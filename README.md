# econ1626-labour-policy-proposal
This repository contains my Assessment 2 submission for ECON1626 – Economics of Artificial Intelligence.
## Policy Focus

The proposal examines how the Australian Government Department of Employment and Workplace Relations (DEWR) could support workers and employers adjusting to AI-related task change while preserving productivity-enhancing AI adoption.
